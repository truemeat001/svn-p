# SVN Desk 原生深色工作台

## 视觉方向

保留 P4V 式高信息密度：左侧目录树，右侧文件与变更列表，下方差异或日志。使用低饱和蓝灰层次、清晰中文字型和单一蓝色主操作，避免营销页面式大卡片、装饰插画、玻璃效果和无功能动画。

这是一套真实 Tk/ttk 控件的样式实现，不是界面概念图、浏览器替身或生成式截图。`svn_client/theme.py` 提供色板与样式，原有 SVN 行为和确认流程保持独立。

## 信息层次

- 左侧栏只承载工作区身份与目录导航，默认约 250–270 个逻辑像素宽，可拖动调整。
- 工作区选择和本地路径保持可见。长路径允许横向阅读，不通过缩小字体硬塞。
- 主工具条仅“提交选中项”突出为蓝色主按钮；新建分组、刷新、查看差异使用次要按钮。还原、删除、冲突标记仍需明确文字与原有确认。
- 文件表格保持 28 个逻辑像素行高；目录树 27。中文主体 10pt，标题 15pt，代码预览使用系统可用等宽字体。
- 变更列表组头单独深蓝背景，成员行使用常规背景；冲突、添加、缺失同时显示文字状态，不能只靠红绿区分。
- 下方差异用浅绿字/暗绿底表示增加、浅红字/暗红底表示删除，保留 `+`、`-` 和 diff 标头。
- 多按钮行继续使用自动换行工具条。不会为“整齐”而把高 DPI 下的操作挤出屏幕。

## 实现入口

- `apply_theme(root, display)`：在创建控件之前应用样式，使用现有 DPI 字体与像素换算。
- `COLORS`：只读语义色板，包含正文、次要文字、按钮、焦点、选中状态、分组、状态和差异颜色。
- `text_options(kind)`：普通 Tk Text 使用统一配色；`normal` 对应预览，`console` 对应日志，`input` 对应提交说明或合并编辑器。
- 侧栏可使用 `Sidebar.TFrame`、`Sidebar.TLabel`、`SidebarMuted.TLabel` 和 `Navigation.Treeview`；普通内容面板使用 `Surface.TFrame`。
- `White.TFrame` 保留兼容名称，但已改为深色内容面板，避免漏改造成白色空洞。

菜单和下拉列表单独配置 Tk 选项。系统原生文件选择器、消息框和标题栏可能继续使用系统外观，不伪造这些系统界面。

## 可读性检查

色板计算采用 W3C 的 sRGB 相对亮度方法。默认正文/内容面板对比度约 14.19:1，次要文字约 7.35:1，主按钮白字约 5.34:1，悬停主按钮白字约 4.72:1。新增测试覆盖正文、次要文字、状态文字、选中状态、diff、输入框边界、焦点与滚动条；这只是色彩检查，不代表完成整套无障碍认证。

设计参考：[W3C 文本对比度说明](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum)。

## 验收范围

必须使用运行中的实际应用检查：空工作区、演示数据、长中文路径、展开/折叠分组、选择/取消选择、禁用和悬停按钮、下拉菜单、提交对话框、冲突对话框和取消流程。特别检查 Windows 100%、125%、150%、200% 下的文字与裁切，以及窄窗口下所有操作是否仍可触达。

当前模块测试不依赖图形显示器，只验证色板和样式调用；不能替代原生 Windows 外观实测。任何截图都应来自实际运行界面，并标明运行平台和演示数据状态。
