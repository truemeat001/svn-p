# 连接诊断界面

入口：**文件 → 连接诊断（本地 / 显式 URL）…**。实现为真实 Tk 窗口，不是网页或截图。底层只读行为与错误分类见 [连接诊断模块](CONNECTION.md)。

## 本地检查

打开窗口不会自动执行命令。点击 **本地检查（不连接服务器）**，才在后台读取 SVN 版本和当前工作副本的本地身份。未打开工作副本时，只检查 SVN 程序。使用当前副本实际使用的 SVN 程序；没有打开副本时，使用文件菜单配置的程序或正常发现流程。

本地身份中的 URL 只是 `.svn` 中记录的元数据。不会跟随该 URL 访问服务器，也不会把它自动填入远程输入框。本地检查成功不能解释成“服务器已连接”。

启动时主动打开诊断会取消本次待执行的自动恢复，避免模态窗口下方突然切换工作副本。此行为不更改下次启动的恢复偏好。

## 明确检查一个 URL

1. URL 输入框初始为空，远程同意框初始未勾选。
2. 输入确切 `http://`、`https://`、`svn://` 或本机 `file://` URL。
3. 勾选“我明确选择检查所填 URL”，再点击 **核对 URL 并检查…**。
4. 确认窗口完整显示 URL，默认选项是“否”。确认后才执行一次只读 `info`。

修改 URL 会清除同意；每次请求开始也清除同意，下次检查需重新勾选和核对。取消、关闭或上下文变化不会触发替代地址、自动重试或隐式操作。

拒绝包含用户名、密码、查询参数、fragment、控制字符或不安全结构的 URL；无效输入会清空，不在提示或日志回显。不支持 `svn+ssh` 远程检查，也没有账号、密码、验证码或证书信任输入框。本地 SSH 身份可以按底层规则去掉用户名后显示，但不会用于远程访问。

URL 路径按字面解释，在 HEAD 读取。例如 `.../name@123` 指名为 `name@123` 的路径，不是历史修订 123。此规则不同于检出输入支持的 SVN peg 语法，确认窗口会明确提醒。

现有 SVN 配置或凭据缓存可能用于远程请求，服务器可能记录访问。程序不收集或传递新凭据、不写新认证缓存、不接受或忽略证书、不修改代理，不进行更新、检出、提交、加锁或权限“试写”。TLS 错误只提示核对可信配置，不提供绕过入口。

## 结果与隐私

报告分别显示 SVN 程序、本地工作副本、显式 URL、可用时的仓库 UUID 比较。每步标明成功、失败或跳过，并给出固定中文排查提示与数字错误码。

- 本地成功不代表远程成功；远程已尝试启动也不能证明服务器收到了请求。
- UUID 相同不证明 URL、分支、修订或内容一致。不同 UUID 不会触发 switch 或 relocate。
- `info` 成功不能证明提交、锁、hooks、检出或其他目录权限可用。
- 窗口仅显示允许的身份字段与固定分类，不复制原始进程输出、原始 XML、任意服务端说明、证书内容、作者或锁令牌。
- URL 输入和报告不写入程序日志或设置，不自动导出。日志只记录固定的“生成连接诊断”任务说明；未预期异常也在进入共享日志前替换成固定说明。
- 报告包含本地路径和仓库身份，分享截图前仍应检查。程序没有自动分享或上传功能。
- 报告显示上限为 64 KiB，超过时拒绝展示，不把截断内容伪装成完整报告。底层 2 MiB XML 限制是捕获后的解析限制，不是全程进程内存配额。

## 异步与关闭

检查在后台线程运行，不在 Tk 回调中执行 SVN 或文件读取。运行期间检查按钮和 URL 控件禁用，主窗口不会并发开始其他操作。关闭诊断窗口只放弃显示结果，不声称终止已启动进程；进程会继续到完成或其超时，结果不会保存。主程序仍等待此次任务结束后再允许正常退出。

回调绑定窗口存活状态、请求代次、当前客户端、工作副本路径和 SVN 程序配置。旧结果不会覆盖重新打开的诊断窗口或应用到另一工作区，也不改动主窗口文件详情、历史或导航。

每个 SVN 子进程默认超时 15 秒，最多依次执行三个进程；这不是整个报告的总时限，也不覆盖进程创建或第三方认证设施的所有行为。没有后台轮询、自动重试或自动修复。演示模式不构造真实诊断器、不读取真实 SVN 配置或工作副本，也不发起请求。

## 验证边界

`python -m unittest discover -s tests -p test_connection_ui.py -v` 覆盖默认不开启远程、完整确认/取消、输入变更撤销同意、上下文/关闭失效、错误脱敏、精确后台参数、报告语义和模拟控件构造。底层另有 [模块测试](CONNECTION.md)。

这些是无显示环境中的单元/模拟测试，不是原生 Windows/live Tk 视觉验收，也不是实际 SVN、网络认证或 TLS 端到端验收。当前环境没有 `svn` / `svnadmin`，对应真实集成测试跳过。
