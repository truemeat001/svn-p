# 分支与合并 GUI（严格预览范围）

入口位于顶部“分支与合并”菜单。与文件右键操作不同，切换和合并影响**当前打开的整个实际工作副本根**，不是选中的文件、目录或变更列表。请只先在一次性测试仓库中验证。

此界面调用 [分支后端](BRANCHES.md)，没有独立命令拼接、通用命令框或自动补救步骤。

## 切换整个工作副本

1. 打开并刷新实际工作副本根。选择“切换整个工作副本”。
2. 对话框显示完整根目录、最近读取的 URL 映射和基础修订。目标目录 URL 与数字修订都为空，需要明确填写。
3. 点击“只读预检”。后端重新检查整个副本、目标目录、仓库身份及固定修订。存在未版本化、被忽略或修改的文件等不支持状态会拒绝，不会自动删除、更新或还原。
4. 核对完整根目录、当前映射、目标 URL、固定修订、全部提示和状态摘要。**SVN switch 没有 dry-run**，预检不是切换模拟，也不能提前证明祖先关系、最终成功或没有冲突。
5. 两项确认默认均未勾选：必须核对全副本范围，以及独立保护重要数据、避免并行编辑/编译/SVN 操作并理解部分失败风险。再明确点击“切换整个工作副本”才执行。
6. 执行前复核同一预检摘要，完成后复核实际 URL、修订与干净状态。没有仓库提交。

## 合并明确的向前范围

1. 选择“合并明确向前范围到整个副本”。填写源目录 URL、起始修订和结束修订。
2. 只支持 `0 ≤ start < end`，每次最多 64 个修订。范围是 **(start, end]**，即起始之后到结束为止，不是从第 start 次提交起；来源固定为 `URL@end`。
3. 点击“只读预检”后会实际运行 SVN `merge --dry-run`。核对窗口完整显示返回的 dry-run 文本及全部提示，不用截断预览替代执行确认。
4. 若预演标出冲突，执行入口禁用；不会把其中一部分静默排除后继续。如果未标出冲突，仍不保证真实合并完整或无冲突，已有 mergeinfo 可能跳过已合并修订。
5. 同样需要两项明确确认，才能应用一次本地合并。结果保留为待审查的内容/属性修改，可能包含 `svn:mergeinfo`，**不会自动提交**。
6. 实际合并产生冲突时保留结果，提示人工核查，不自动 resolve、revert 或重试。检查状态、差异、mergeinfo 并运行项目测试后，再另行决定提交。

## 分支 / 标签计划仅可读取

菜单明确标为“分支 / 标签计划（只读，不创建）”。填写已提交源目录、固定修订、拟建目录、branch/tag 类型和拟提交说明后，可进行只读检查并查看计划。

结果窗口只有“关闭 / 取消”，没有执行按钮。即使计划生成成功也不会发送 `svn copy` 或 `commit`。普通 URL → URL 复制会立即提交服务器，而 CLI 在目标目录竞争情况下可能改变精确目标，因此当前版本刻意不提供创建执行。

计划不包含本地未提交内容，不证明服务器写权限/提交钩子，也不会冻结或跟随 externals。标签仍是普通 SVN 目录，不可修改需要服务器策略保证。不要把计划摘要当作提交授权。

## 范围、状态变化与失败

- 三个入口都要求后端严格支持的完整干净副本：统一 BASE 修订、完整深度，没有外部引用、稀疏目录、已切换子树、未版本化/忽略文件、链接、硬链接或嵌套副本等。首版最多 10,000 个版本化条目和 256 MiB 工作文件。完整条件见 [BRANCHES.md](BRANCHES.md)。
- 只接受明确非负数字修订，不接受 HEAD、BASE、日期或选项。URL 中 `@` 是字面名称，修订单独填写；拒绝 URL 凭据、查询串、片段、路径穿越和 svn+ssh。
- 预检可能读取全树并逐修订访问服务器，耗时较长。全部 I/O 在后台执行。检查返回与最终确认后都核对当前客户端、根目录、URL 映射、修订和请求上下文；变化时不继续旧计划。
- 切换/合并执行前会重新计算状态摘要，不会遇到旧摘要时自动换用新的摘要。预检不是跨进程锁或事务。
- 执行前拒绝与已尝试/无法验证的结果分开提示。错误不意味着回滚；不会自动重试、强制执行、提交或丢弃结果。
- 全副本尝试之后会使旧文件选区、目录/仓库树缓存、历史和映射失效，再重新读取。读取尚未成功时明确显示“工作副本状态未知”，不以“0 个修改/冲突”暗示干净。
- 若结果展示或通知报错，仍安排原副本的重新读取并继续处理后台结果。若已经切换到另一个工作副本，不刷新或覆盖新副本。
- 结果详情预览最多 64 KiB，并标出截断。请结合刷新后的状态列表核对完整实际结果；预检确认文本则完整展示受后端上限约束的 dry-run。
- 演示模式不执行这些真实预检或变更，也不读取用户的真实工作区设置。

## 验证边界

本轮使用无显示回调与模拟 Tk 构造测试覆盖参数、取消、双重确认、预演冲突阻止执行、只读计划无执行路径、精确摘要、上下文变化、结果不确定和缓存失效。没有完成真实 SVN、原生 Windows/live Tk、认证服务器或视觉交互验收。请勿将这些测试通过等同于生产可用。
