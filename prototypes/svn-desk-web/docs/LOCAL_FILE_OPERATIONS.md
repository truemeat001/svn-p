# 单文件本地移动／重命名与带历史复制

这是现代 Web 原型的默认关闭切片，复用校验过源码摘要的原版
`svn_client.fileops.FileOperationManager`，原版代码保持不变。
不是目录管理器，不是远程仓库复制，也不提供删除、覆盖或普通还原。

## 开启与操作

```sh
python server.py --workspace "/path/to/disposable-test-wc" \
  --backend-source "/path/to/paired-original" --enable-file-ops
```

独立开关不会打开其他写功能。工具栏与右键菜单提供「移动／重命名…」
与「带历史复制…」。启用后，本地状态会包含干净文件，便于选择；不自动联网。

1. 完整选区必须只有一个已版本化普通文件。被筛选或折叠隐藏的选中项也计数，
   不会用焦点文件偷偷缩小多选范围。
2. 输入相对于工作副本根的精确目标文件路径，网页目录分隔使用 `/`。
   同目录改名即重命名；不会自动补目录、猜文件名或裁剪输入。
3. 点击预检，核对源和目标后，再单独确认。计划绑定动作、工作区、选择代际、
   成功状态快照、文件内容／属性／身份及目标命名空间，120 秒一次有效。
4. 确认后只有一次原生 SVN 命令。关闭窗口不取消已经开始的操作。

移动会把源路径登记为待删除，目标带历史待新增。复制保留源文件，以 WORKING
内容和属性创建带历史目标。两个动作均不上传或提交。changelist 标签不保证转移。
**当前 Web 提交入口刻意拒绝 copied/moved 等结构变更；请用原版可信 SVN 客户端
审查并提交移动两端或复制目标。不要只提交移动的一端，也不要假定普通 revert
能安全恢复移动两端。**

## 边界

- 只支持一个 `normal` / `modified` 普通版本化文件，普通未变／已修改属性。
  拒绝新增、删除、替换、缺失、复制／移动关系、冲突、外部引用、switched、
  工作副本锁和本地仓库锁元数据；拒绝 `svn:special`。
- 目标必须不存在且没有 SVN 元数据。父目录须已存在、已版本化且在同一根，
  不接受 URL、绝对路径、管理目录、`..`、大小写改名或不区分大小写的名称冲突。
- 拒绝目录、链接、hardlink、Windows reparse/junction、嵌套工作副本和跨设备。
  父目录与根状态／仓库映射会重新核对，不把目录筛选变成操作范围。
- 使用原版 move/copy 的不同 peg 规则：源中 `@` 按空 peg 转义，copy 目标也转义，
  move 目标保持字面路径。不调用 shell，不传 `--force`、递归或自动父目录选项。
- 页面请求只传行 ID、目标、限定动作和一次性令牌；没有通用 argv、任意读取或
  删除接口。继续使用 loopback、Host/Origin、session token 和严格 JSON 验证。

## 限额与结果

单文件最多 32 MiB。内容摘要复用有界分块读取，摘要遍历有协作式 10 秒时限，
整个操作另有 90 秒协作式总期限。每次 XML 256 KiB、元数据累计 8 MiB、完整状态捕获 8 MiB、
修改命令输出 256 KiB；属性读取至多 128 个名称、单个值 64 KiB，继承现有严格属性 XML 校验；目录名称检查最多 50,000 项。超限拒绝而非部分执行、
拆批或降低验证。底层阻塞文件系统调用不能被协作式期限强行中断。

预检与执行前重复检查不会让外部进程成为事务的一部分。请暂停编辑和其他 SVN
操作；尤其目标在最后检查后变成目录，原生 SVN 仍可能采用移入目录语义。
执行后会检查精确路径、内容、属性和复制来源；不一致或执行期错误报告结果未知，
保留现场，不自动重试或回滚。原生命令固定使用 `--quiet`；即使零退出，任何 stdout／stderr（包括空白）也按结果未知处理，不猜测诊断是否无害。命令开始后的超时和输出超限同样不重试。

已核实的移动／复制事实不会被随后的状态刷新失败、关闭窗口或界面采用结果失败
抹去；状态失效则清空列表、撤销写能力并要求明确刷新。结果未知时先用原版可信
SVN 客户端核对源和目标，不能把空列表理解为干净或未执行。

## 验证范围

本切片只执行合成临时目录、模拟 SVN、有界 HTTP 和 DOM-adapter 测试。
浏览器脚本为 `npm run test:file-ops:ui`，仅模拟 API，不能代替原生 SVN。
当前容器的 Chromium 启动此前被 socket 权限阻止，本轮不重复或绕过被拒动作。
**真实 SVN、Windows 文件系统、浏览器实际交互和原生打包尚未验收。**
当前远端基线是属性测试兼容补丁 `59a762b`；该补丁的 Windows 完整重跑与本文件操作切片是不同验收范围。

## 可丢弃 Windows / 真实 SVN 验收清单

只在自建临时 `svnadmin` 仓库和两个隔离工作副本中验证，禁止用户真实工程：

- 默认启动拒绝两个写端点；仅启用本开关可选干净文件，其他写入口仍禁用。
- 普通、修改内容／属性的源文件；同目录重命名、跨已有目录移动、带历史复制。
  核对源保留／删除状态、目标内容和属性、copy-from URL/rev 及移动关联。
- 文件名含 Unicode、空格、前导短横线、字面 `@`；核对 copy 与 move 目标没有
  被错误追加 `@`。用原版客户端提交移动两端，再独立核对历史。
- 同名、大小写冲突、父目录缺失、目录、跨根、external、switched、链接、
  reparse、hardlink、工作副本锁和本地仓库锁均拒绝。
- 预检后改文件、等长修改还原 mtime、改属性、改祖先状态、目标被占用、令牌
  过期／复用／跨标签页；不得修改或自动重试。
- 失败／诊断／超时可能部分完成；检查两端与日志，不能声明回滚。
- GUI：隐藏多选禁用，目标编辑使计划失效，预检不会修改，双击确认只发一次，
  关闭／Esc／切换和迟到响应不重新开窗；已核实结果跨刷新失败保留。
- 复跑所有现有只读、属性、添加、Shelf、归组、锁、提交回归，明确记录 GUI
  与原生包装是否实际执行。
