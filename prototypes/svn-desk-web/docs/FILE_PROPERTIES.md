# 真实文件属性审查：WORKING / BASE

这是 `d01bf15` 后的现代 UI 只读切片。原来的「属性」标签只显示 status 元数据；现在可显式读取当前单文件的 SVN 属性值，对照 WORKING 与 BASE，方便检查 `svn:mime-type`、`svn:needs-lock`、`svn:eol-style` 和自定义属性。没有设置/删除属性、提交、远程修订或任意命令入口。

## 使用

使用现有真实工作区启动方式即可，不需要开启任何写权限：

```sh
python3 server.py --workspace "/path/to/disposable-test-wc" \
  --backend-source "/path/to/paired-original"
```

1. 选择一个已版本化普通文件，点击底部「属性」、详情里的「查看本地属性」，或文件右键菜单的属性入口。打开面板不发起 SVN 查询。
2. 单独点击「读取本地属性对照」。只读取焦点文件，其他选中或隐藏文件不会被读取。
3. 查看新增、移除、修改和未改变的属性。空字符串、没有此属性、二进制值是不同状态。普通文件的 BASE 读取必须成功，否则整次失败；新增文件明确显示「没有 BASE」，不会假造一个空 BASE。

使用本地 `proplist --xml --verbose --depth empty`；BASE 一侧固定 `--revision BASE`。不使用 HEAD、网络 URL、继承属性、递归或 SVN 属性写命令。网络挂载的工作副本仍可能访问该文件系统，但本功能不向 SVN 仓库发起查询。

默认状态仍只展示已有变更范围。需要查看干净文件时，本轮不为此额外扩大状态范围；已启用仓库锁的现有模式会显示干净行。演示模式仍仅显示明确标注的示例状态元数据，不伪造属性值。

## 读取与显示边界

- API 仅接受工作区 ID、选择代际、成功状态快照和现有行 ID。不能从网页输入路径、URL、属性名、修订或命令。
- 服务前后核对明确行状态、文件身份、当前工作副本/仓库身份和属性快照。文件必须存在；拒绝未版本化、删除/替换、冲突、复制/移动、外部引用、switched、带管理锁标记的条目、目录、链接、hardlink、reparse、嵌套工作副本和跨设备路径。
- XML 严格检查目标、节点、属性、重复属性名、编码和大小；拒绝 DTD/ENTITY、NUL、附加结构或错误目标。Windows 仅接受本地路径分隔符的等价表示，不放宽绝对路径、父目录或大小写别名。
- 每次属性 XML 捕获最多 1 MiB；两侧合计最多 128 个属性名、256 KiB 原始值，单值最多 64 KiB。显示响应最多 512 KiB，超出整体上限不返回部分列表。
- 每个文本值最多展示 4096 UTF-8 字节。URL 凭据先遮蔽，控制字符（包括换行、制表符和双向格式字符）显示为可见转义，再截断。显示会标出遮蔽、转义或截断；不是精确导出或补丁。
- 不可按 UTF-8 解码或含 NUL 的值只显示字节数与 SHA-256，不向页面传送二进制载荷。属性是否改变由完整原始字节决定，不依赖显示结果；两段都被遮蔽或截断的文本仍可能不同。
- 属性值可能包含项目私有信息，页面仅本地展示，不自动分享，也不把属性名/值写入操作日志。URL 遮蔽不是通用秘密检测器，请自行判断是否可以分享截图或文本。
- 使用严格有界传输：任何 stderr，即使退出码 0 或只是空白，也不接收结果；原始诊断不进入网页。每个 SVN 子进程沿用 25 秒超时，多次查询不是一个总超时。重复检查只能发现观察到的变化，不构成跨进程原子快照。

切换文件/工作区、刷新、关闭预览、打开其他操作或切换标签后，旧结果和未完成请求失效。迟到响应不恢复旧面板。失败清除旧结果并明确显示属性未知，不能解释为没有属性。浏览器同时检查响应的 BASE 是否可用必须与发起请求时的文件状态相符。

## 验证情况

新增服务、桥接、模型、实际控制器 DOM-adapter 和独立 Python→JavaScript 序列化契约回归，均使用合成临时目录、模拟 SVN 和本机 HTTP，没有操作用户真实工作副本。独立审核补充 BASE 可用性必须绑定请求时状态的对称回归，并覆盖二进制/空值、Unicode、控制字符、结构噪声和完整字节比较。

浏览器脚本为 `npm run test:properties:ui`。当前环境上一轮已确认 Chromium 在启动时被 `socket() failed: Operation not permitted` 限制，本轮未重试被限制的启动或绕过权限；本轮浏览器断言、真实 SVN、Windows 和原生包装均尚未验收。前一轮 `d01bf15` 添加功能的 Windows 验证不代表本属性切片通过。

后续在自建可丢弃 Windows 仓库检查：

- 现有普通文件 WORKING/BASE 的新增、移除、修改、空值、多行值和无属性结果；新增文件明确没有 BASE。
- `@`、中文、空格和前导 `-` 文件名，以及 SVN XML 的本地分隔符兼容。
- 属性预览只读，不改变工作副本；BASE 失败不能转成空 BASE；严格拒绝目录、冲突、switched/external 和链接。
- 切换文件、标签、工作区、关闭预览、快速重复点击与失败恢复，确保没有旧结果闪回。
- 截断、遮蔽、控制转义和二进制摘要显示，以及前一轮添加后检查 MIME 属性再另行提交的操作闭环。
