# 现代 UI：明确新文件添加到版本控制

这是 `4554f2f` 后的独立 opt-in 开发切片，不是可发布客户端。只将 1–100 个明确未版本化普通文件登记到当前工作副本，不提交或上传到仓库；不自动添加父目录、不递归、不使用 force / no-ignore，也不提供任意 SVN 命令入口。原版后端源码保持不变。

## 启用与操作

```sh
python3 server.py --workspace "/path/to/disposable-test-wc" \
  --backend-source "/path/to/paired-original" --enable-adds
```

未启用时工具栏与右键菜单入口禁用；离线演示不伪造添加成功。严格配套 backend/history 源码指纹核对通过后才提供能力，CRLF 换行不影响核对。`--enable-adds` 不启用归组、Shelf、仓库提交或锁。

1. 选择未版本化文件。完整选区包含被筛选或折叠隐藏的文件；任一成员不合格即拒绝整次预检，不跳过或扩大范围。
2. 点击「添加文件…」或右键「添加选区到版本控制…」。窗口列出完整路径及本地操作说明，打开不执行 SVN。
3. 点击「预检明确选区」。核对本地状态、已版本化父目录、真实文件身份和有界 SHA-256 内容摘要，不访问仓库。
4. 另行点击「确认添加到本地版本控制」。成功后显示待添加状态，仍须自行审查文件属性和差异，再使用独立提交流程。

显式关闭 `auto-props`，防止本地配置或继承自动属性隐含扩大本次添加设置。SVN 仍可能按文件类型检测并设置属性，例如 `svn:mime-type`；这不是“保证零属性”。需要团队 auto-props 规则的工程请使用可信完整客户端处理，不能把本功能当成自动应用团队属性的工具。

## 计划和限制

- 只接受当前成功状态快照里的确切行 ID，不接受 URL、任意路径、目标目录或 CLI 参数。ID 按大小写折叠去重，单次目标参数 UTF-8 预算 24,000 字节，Windows 长命令在执行前保守拒绝。
- 未版本化文件必须已存在且是普通文件，父目录一路到根都已正常版本化。拒绝目录、链接、hardlink、reparse point、跨设备、嵌套工作副本、external、switched、管理锁、冲突、结构变化和不安全路径。不会为了使预检通过而添加父目录、改权限或移除忽略规则。
- 刷新使用本地 verbose 状态取得父目录身份，但 UI 仍只展示原有变更/标签范围，除非另行启用了需要显示干净文件的仓库锁能力。不会使用 `--show-updates`。
- 一次性计划绑定工作区、选择代际、快照、完整行状态、父目录 SVN 身份和文件身份+摘要；120 秒有效。执行前消费计划并重新核对，命令前失效所有其他写计划与旧快照。刷新、切换、改选区和关闭窗口也会失效 UI 确认。
- XML 身份忽略属性插入顺序，保留属性值、文本、tail 和子节点顺序。有效的不同顺序不应误伤；实际元数据改变仍拒绝。
- 每文件最多 32 MiB，每遍选区最多 64 MiB，以 64 KiB 块计算摘要，每遍累计 10 秒协作式时限。原有 status 上限 50,000 项、严格有界本地 info、每个 SVN 命令 25 秒仍适用。多次元数据查询可能使整个预检超过单个命令时限；文件系统阻塞不可强制中断。
- 使用固定参数数组 `add --depth empty --no-auto-props -- <exact targets>`，不调用旧版会添加父目录的 `add()` 辅助方法，不运行 shell。路径包含 `@` 时沿用正确的字面路径保护。

## 结果与失败

零退出码不等于已验证成功。命令返回后核对全部选中项为 `added`、本地文件身份/摘要不变、父目录身份不变、未选择行状态不变，并重新读取状态。任何 stderr、异常、超时、部分成功或事后验证失败都显示结果未知，不自动重试或回滚。

关闭正在执行的窗口不取消命令。状态先失效，已核实的完成结果仍会保留在页面和操作日志里，即使窗口关闭、状态发布失败或前端状态应用失败。失败时可能有文件已经登记，请明确刷新并核对再决定下一步。文件摘要不能把多个进程和 SVN 命令变成原子事务，请不要并行编辑或运行其他 SVN 操作。

## 验证边界

本轮服务/HTTP/模型/真实控制器代码的 DOM-adapter 测试均使用合成目录和模拟 SVN。独立审核补充了 XML 属性顺序、过期计划、根目录管理锁、执行后工作区验证失败和前端快照失败后保留成功事实的回归。

提供 `npm run test:adds:ui` 合成浏览器契约测试。当前环境的 Chromium 在启动阶段因 `socket() failed: Operation not permitted` 中止，测试断言尚未执行，没有绕过权限限制。当前环境没有 `svn` / `svnadmin`，没有真实 SVN、Windows、WebView2 或原生打包验收结果。

在自建可丢弃 Windows 仓库验收：

- 未启用时禁止入口；仅启用 add 后其他写入口保持禁用。
- 已版本化父目录中的中文、空格、`@`、前导 `-` 普通新文件添加成功；隐含父目录、新目录、忽略项、链接、external、switched/管理锁拒绝。
- 隐藏多选完整保留；预检不添加；关闭/重开、刷新、换工作区、内容同长改写并还原 mtime 后需重新预检。
- 在测试配置中启用 auto-props，确认本流程不套用自动属性；检查 MIME 默认属性；提交前单独审查。
- 多文件错误或关闭期间不得自动重试，确认旧计划不可重用；验证真实新增文件能接上已有提交工作流，但不得自动提交。
