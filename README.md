# SVN Desk（预览版）

一个参考 P4V 工作流的 SVN 桌面客户端原型。使用系统安装的 `svn` 命令，不包含 SVN 客户端、Python、安装器或可执行程序。本版尚未验证真实 SVN 仓库或 Windows 图形界面，不应直接用于重要项目；请先在一次性测试工作副本中验证。

## Windows 运行

1. 安装可信来源的 Python 3.10 或以上版本，并确保安装时包含 tkinter；安装官方认可发行渠道提供的 Subversion 命令行客户端，确保 `svn.exe` 可用。
2. 解压整个文件夹，双击 `启动.bat`，或在该目录打开终端执行 `py -3 main.py`。只读示例界面：`py -3 main.py --demo`。
3. 在界面选择已有工作副本。网络仓库认证需要事先通过可信 SVN 客户端配置；本工具不请求或存储密码，不支持交互式认证提示。

## 现有功能

- 工作副本、待提交项、文件、历史、仓库浏览、差异及操作记录。
- P4V 式功能布局：可调整宽度的左侧工作副本/仓库导航，右侧对象页签，下方详情/差异/记录。工作副本目录在展开时后台读取；宽目录每次展开 200 项，文件页使用上一页/下一页浏览，不再限制为整棵目录前 3,000 个文件。选择目录只改变浏览范围，不会自动选中文件用于递归提交。
- 工具栏随可用宽度换行。文件与列表使用不同右键菜单；没有适当选中对象时禁用对应动作。选择对象立即更新详情，显式双击/差异按钮读取文件内容；过期的读取结果不会覆盖新选中对象的详情。
- 状态、添加、更新、提交、还原等常用 SVN 操作。**界面没有通用 SVN 命令输入框**；未覆盖的功能请使用外部 SVN 客户端。图形化流程并不覆盖全部 SVN 功能，且受安装的 SVN 版本与权限限制。提交、还原等有风险，请阅读确认提示。
- 原生 SVN 变更列表：创建并归组、移动选中文件、移回未分组、按列表分组展示、确认后提交整个选中列表。正常但已归组的文件也会显示，但不计入待提交修改数。
- 本地备份（搁置）：保存选中改动的文件内容和 SVN 属性，包括受支持的新增、删除和未版本化文件；创建备份不会清空工作区，也不会上传服务器。恢复前会校验仓库、基础版本、工作区内容和目标路径，存在冲突则拒绝。**当前 Shelf 不保存或恢复变更列表标签**，恢复后可能需要重新归组。
- 不支持的状态会明确拒绝，例如复制/移动、替换、冲突、切换、外部引用、符号链接/重解析点、删除目录。备份不保证保存 ACL、所有者或全部时间戳，也不是服务器端 P4 shelf；备份请另行复制到可靠存储。

## 创建与提交变更列表

1. 打开工作副本，在“待提交更改”上方点击 **+ 新建变更列表…**。
2. 填写名称，从对话框中选择一个或多个已版本化文件，点击“创建并归组”。也可预先选中文件，再点击新建。未版本化文件要先“添加”；目录不能归组。
3. 列表和文件以可展开分组显示。选中文件后点击“移动到列表…”选择已有列表或输入新名称；右键菜单提供同样操作。
4. 要取消归组，选择文件行并点击“移回未分组…”。这只清除标签，不会还原或删除内容。
5. 要提交整个列表，选中命名列表标题并点击“提交所选列表…”。确认窗口列出该列表全部成员，包括筛选隐藏的文件；核对并输入提交说明后才发送到仓库。成员在确认后发生变化时，会拒绝提交并要求重新检查。

**与 P4V 不同：** SVN 变更列表是工作副本本地标签，不是服务器编号提交单，不保存文件内容，不提供锁定或跨电脑同步。一个文件只能属于一个列表，不能创建持久空列表；最后一个成员移走后列表自动消失。默认提交后，成功提交文件的分组标签会被 SVN 移除。创建、移动和移除分组不会修改文件内容。新增目录等依赖可能导致 SVN 拒绝按文件列表提交，本工具不会自动扩大范围。其他程序仍可在提交期间修改文件内容，请不要并行编辑或运行会修改同一工作副本的工具。

当前没有拖放归组、P4V 式独立提交单编辑器或可持续运行的自动状态监控；列表移动使用明确的按钮与右键流程。目录导航按需读取，SVN 状态查询仍是工作副本级，右侧待提交树还不具备虚拟化。当前实现不是性能跑分结论，也没有复刻 P4V 的全部功能。

## 测试与注意事项

在项目目录执行 `python -m unittest discover -s tests -v`。部分集成测试需要 `svn` 与 `svnadmin`。本次开发环境中二者不可用，真实仓库测试跳过；原生 Windows、GUI 展示、认证及安装流程也没有验证。启动前请使用测试仓库，独立备份重要工作副本；不要在恢复期间同时修改工作副本。

命令超时不意味着服务器事务被撤销，提交等操作中断后应先核查仓库状态，勿盲目重试。

## 面向 AI 的 CLI

使用 `python -m svn_client.cli --workspace 工作副本路径 status` 获取 JSON；详见 docs/CLI.md。涉及修改的命令需明确确认或 dry-run。
